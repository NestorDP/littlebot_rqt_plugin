Littlebot RQT Plugin Documentation
==================================

Welcome to the technical documentation of the Littlebot RQT Plugin.

The ``littlebot_rqt_plugin`` package provides a graphical interface for
monitoring and interacting with the Littlebot robot through ROS 2.

This documentation covers the installation, usage, software architecture,
and development of the plugin.
